## CI (GitHub Actions)

`.github/workflows/playwright.yml` – dwa joby:

1. **quality** – `typecheck`, `lint`, `format:check`. Uruchamiany automatycznie przy każdym pushu i pull requeście do `main`.
2. **test** – testy e2e w Chromium (na CI `workers: 1`, `retries: 2`). Raport HTML i `test-results/` jako artefakt. **Tylko ręcznie** (Actions → Playwright Tests → _Run workflow_): testy działają na współdzielonym dev i część z nich tworzy dane (zgłoszenia, pozycje słownika, generowanie plików), więc nie startują przy pushu.

Uruchomienie ręczne przyjmuje filtr tagów, np. `@smoke`, `@P1`, `@TS_01` (puste = wszystkie testy).

Wymagana konfiguracja repozytorium (Settings → Secrets and variables → Actions):
